# 식별자는 온톨로지 층 기준 파일 경로에서 확장자를 뺀 것이고 클래스 디렉토리로 시작한다(`plan/auth-redesign`). 경로의 각 조각은 영어 소문자, 숫자, 하이픈만 쓴다.
# 값의 형식과 쓰는 법은 conventions.md에 있다.
# 본문과 값은 conventions.md의 "페이지는 원본에 근거한다"를 따른다.
class: Plan

description:  # 한 줄 설명
aliases: []   # 다른 이름. 한국어와 영어 별칭을 둔다
date:         # 계획을 세운 날짜. YYYY-MM-DD
about:        # 이 계획이 다루는 Component나 Project의 식별자. 프로젝트 자신은 `project`다. 목록도 된다
supersedes:   # 이 계획이 대체하는 옛 Plan
derivedFrom:
  - path:     # 근거로 삼은 원본 문서의 저장소 루트 기준 경로(예: `docs/plan.md`). 근거가 여럿이면 항목을 더한다
    hash:     # 그 문서의 git 해시. `status`가 보여 주는 현재 해시를 따옴표로 감싸 옮긴다. conventions.md의 "원본 문서"를 본다
