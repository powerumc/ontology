# 최신화

최신화는 루트 저장소의 기능을 지식 저장소의 루트 관리 파일에 반영하는 일입니다. 루트 저장소에서만 쓸 수 있습니다.

```sh
just onto sync [이름]    # 이름을 생략하면 모든 지식 저장소에 반영합니다
```

## 언제 실행하나

- 루트의 `onto/`나 스킬(`.claude/skills/onto-*/`)을 고친 뒤
- `just onto validate`가 `outdated-managed-files`로 최신화가 필요하다고 경고할 때

`just repo add`와 `just setup`이 최신화를 함께 실행하므로, 새로 붙이거나 새 기기에서 클론했을 때는 따로 실행하지 않아도 됩니다.

에이전트에게는 "모든 지식 저장소를 최신화해 줘"나 "billing만 최신화해 줘"라고 하면 됩니다. 이 작업에는 스킬이 없고, 에이전트가 위 명령을 찾아 실행합니다.

## 바뀌는 것과 바뀌지 않는 것

| 대상 | 최신화의 동작 |
|---|---|
| 루트 관리 파일(`.onto/`, `.claude/skills/onto-*/`) | 루트의 내용으로 덮어씁니다. 루트에서 없앤 `onto-` 스킬은 지식 저장소에서도 지웁니다. |
| 마지막 최신화 뒤에 손으로 고친 루트 관리 파일 | 덮어쓰지 않고 파일마다 이유와 함께 알립니다(종료 코드 1). 루트의 내용으로 되돌리려면 그 파일을 지우고 다시 실행합니다. |
| 지식 저장소 팀의 스킬(`onto-`로 시작하지 않는 것) | 건드리지 않습니다. |
| 지식 저장소의 `Justfile`, 페이지, `ontology.yaml` | 바꾸지 않습니다. 새 구조 제약에 어긋나게 된 페이지는 마지막에 알리기만 합니다. |

변경은 지식 저장소의 작업 트리에 남고 커밋하지 않습니다. 두 번 실행해도 두 번째에는 아무것도 바뀌지 않습니다.

표시된 블록을 넣는 위치, 심볼릭 링크로 된 지침 파일의 처리, 공통 어휘의 버전을 올리는 기준 같은 세부 동작은 [`onto/README.md`](../../onto/README.md)에 있습니다.
