# 루트 저장소는 받아서 자기 원격으로 바꿔 쓰고, 공개 원본에는 지식 저장소를 등록하지 않는다

이 저장소가 루트 저장소다. 누구나 받아서 `origin`을 자기 원격으로 바꾸고, 자기 지식 저장소를 git 서브모듈로 등록해 그 루트 저장소에 커밋한다. 공개 원본에는 어떤 지식 저장소도 등록하지 않는다. 받아 가는 사람에게 남의 저장소 목록이 딸려 가면 안 되기 때문이다.

## 검토한 대안

- **`projects/`를 `.gitignore`에 넣고 일반 클론으로 붙이기**: 공개 원본에 게시될 일은 없지만, 받아 쓰는 사람이 자기 저장소 구성을 커밋할 수 없어서 기각했다.
- **비공개 저장소가 이 저장소를 서브모듈로 품기**: 등록 정보와 기능이 구조적으로 분리되지만, 이 저장소가 루트라는 단순한 모델이 깨지고 구성 단계가 늘어나서 기각했다.

## 결과

- 받아 쓰는 루트 저장소와 공개 원본은 같은 코드이고 원격만 다르다.
- 공개 원본을 고치는 작업 사본에서는 지식 저장소를 등록하지 않는다. `origin`이 공개 원본이면 등록 명령이 거부한다. 시험은 임시 디렉토리에 만든 루트 저장소에서만 한다.
- 받아 쓰는 루트 저장소가 공개 원본의 갱신을 받아 오는 일은 일반 git으로 한다.
