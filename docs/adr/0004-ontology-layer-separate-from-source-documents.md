# 온톨로지 층은 원본 문서와 분리하고 원본 문서는 고치지 않는다

지식 저장소의 기존 문서(계획, 정책·정의, 구현 결과, 스킬이 쓴 계획 문서)는 원본 문서로 그대로 두고, 온톨로지 층은 `docs/ontology/`에 따로 만든다. 스킬이 만든 문서는 그 스킬이 형식을 소유하므로, frontmatter를 덧붙이면 재생성 때 충돌하기 때문이다.

## 결과

- 페이지는 근거가 된 원본 문서의 경로와 git 해시를 기록한다. 원본 문서가 바뀌면 그 페이지는 낡음으로 표시된다.
- 원본 문서마다 페이지를 만들지 않는다. `Source` 엔티티는 페이지의 기록에서 만들어진다.
- 코드는 원본 문서로 삼지 않는다. 페이지의 내용을 대조할 때만 본다.
