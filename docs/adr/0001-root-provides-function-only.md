# 루트 저장소는 기능만 제공하고 지식은 지식 저장소에 둔다

루트 저장소는 도구, 공통 어휘, 규칙, 템플릿만 갖고 페이지는 하나도 담지 않는다. 지식은 모두 서브모듈로 붙는 지식 저장소에 있으며, 개인 지식도 별도의 비공개 지식 저장소로 만든다. 각 지식 저장소가 단독으로 열려도 자기 지식만 제공해야 하고, 팀과 공유하는 저장소에 개인 지식이 섞이면 안 되기 때문이다.

## 검토한 대안

- **중앙집중형**: 위키를 루트에만 두고 서브모듈의 문서는 원본으로만 쓴다. 지식 저장소를 단독으로 열면 지식이 없어서 기각했다.
- **루트가 개인 지식과 종합 지식도 담는 방식**: 루트가 다른 지식 저장소와 다른 특수한 존재가 되어, 공유 범위를 루트에만 예외로 다뤄야 해서 기각했다.

## 결과

- 지식 저장소의 어떤 파일도 루트 저장소나 다른 지식 저장소의 파일 경로를 가리키지 않는다. 다른 저장소의 엔티티는 교차 참조로만 가리킨다.
- 여러 프로젝트를 비교·종합하는 지식은 개인 지식 저장소에 둔다.
- 공유 범위가 더 좁은 지식 저장소의 엔티티는 참조할 수 없다. 팀 저장소가 비공개 저장소의 이름을 드러내지 않게 하기 위해서다. 이름이 다른 팀 저장소끼리도 같은 이유로 참조할 수 없다.
- 격리는 저장소의 내용으로 보장한다. 루트 저장소 안의 서브모듈 경로에서 에이전트 세션을 시작하면 루트의 지침 파일도 함께 읽히므로, 루트의 지침 파일에는 지식을 적지 않는다.
